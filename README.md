# SquareFight

Local 2-player-multiplayer shooter game where squares fight. 

## How to run

This project uses Unity `2021.2.12f1`, so download that.
Once this repository is cloned, use Unity Hub to open the project. Choose the folder `SqrFight_TheRepo/SquareFight`

### Controls

Left controls:
- Left/Right: $A$ / $D$
- Jump: $W$
- Discard weapon: $Q$
- Shoot: Spacebar
- Interact: $S$ (with moving platforms)

Right controls:
- Left/Right: $\leftarrow$ / $\rightarrow$
- Jump: $\uparrow$
- Discard weapon: $.$
- Shoot: $/$
- Interact: $\downarrow$ (with moving platforms)
